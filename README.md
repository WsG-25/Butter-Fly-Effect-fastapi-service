# Butter-Fly-Effect

## Description

Simple FastAPI web service.

## Prerequisites

Python 3.x
Git

## Clone

git clone <repo>

## Create Virtual Environment

python -m venv .venv

## Activate

Windows

.venv\Scripts\activate

## Install Dependencies

pip install -r requirements.txt

## Run

uvicorn main:app --reload

## Open

http://127.0.0.1:8000
